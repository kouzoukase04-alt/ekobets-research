# ekobets-research

Econ student at Virginia Tech. I build quantitative sports models that hunt
for mispricings in the market, test them against closing lines, and track
how accurate they are over 100+ plays.

## What's here
- **Diagnostics**: scripts that compare my models to market prices
- **Notebook**: one sport's model pipeline
- **Cards**: real daily cards, including a no-play day
- **Results**: graded records, losses included

## One finding
My soccer model was doing much worse than the market. I found the Elo
ratings were being matched to games by row number, so about 90% of games
had the wrong ratings. After fixing it, the model came in close to the market.
